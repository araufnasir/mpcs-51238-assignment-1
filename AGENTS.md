# Project
Landing page explaining price elasticity in plain language: "What does a price change actually do?"

# Audience
Curious non-economists: small business owners, students, anyone who sets or pays prices. No jargon without explanation.

# Visitor should
Understand in under a minute that demand reacts to price, that some products react more than others, and why that matters. Optional: play with a simple price-vs-demand interaction.

# Assignment
- 25 versions in /v01 ... /v25, each a distinct landing page (v01/index.html etc.)
- index.html is the gallery: a card per version with a thumbnail or preview, a one-line note on what changed, and a link. Plus a "Final choice" section telling the process story.
- Each version has a "← Gallery" link back to /
- v01-v12: radically different directions (layout, mood, era, tone), not just color or font changes
- v13-v25: converge on what works for the audience, combining the best elements
- Commit after every version with a message describing the direction

# Constraints
Plain HTML/CSS, optional JS. No frameworks, build step, external APIs, or data storage. Push back if I ask for or you want to add any. Keep code minimal, readable, no repetition. Every version must look clearly unlike the others.
